# ЧЕРНОЗЁМ

Демо-сайт ресторана авторской кухни на местных фермерских продуктах — учебный проект для портфолио.

Стек: HTML / CSS / JavaScript, GSAP + ScrollTrigger, Lenis (плавный скролл).
